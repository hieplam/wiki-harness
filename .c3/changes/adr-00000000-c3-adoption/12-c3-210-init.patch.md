## Goal

Stamp a brand-new wiki instance from scratch — scaffold, seed, hooks wired, first commit made —
so a fresh wiki is immediately lint-clean and ready to ingest, in one `python3
wiki-harness/init.py <target-dir> [flags]` invocation.

| Depended on by | Nothing inside `c3-2`; `c3-211` (upgrade)'s scratch-copy render logic (step 9) reuses the same per-role copy/render behaviour this component defines for a fresh stamp |

## Purpose

Own `init.py`'s 16 ordered, fail-closed steps (plan-v3 §3.1): resolve target, collect the 4
template variables (+ `--origins`), `git init`, create the three `.gitkeep` placeholders, copy
scripts/hooks verbatim, render `AGENTS.md`/`README.md`, copy MANAGED files verbatim, seed SEEDED
files, seed the 4 tracked `CLAUDE.md` stubs, write the manifest, wire `core.hooksPath`, self-verify
by actually running `lint.py` and both hooks, make the real first commit, verify it landed, print
the summary. Non-goal: `init` never runs again against an already-initialized wiki — that is
`c3-211` (upgrade)'s job entirely; the two share `c3-201`/`c3-3` but not each other's flow.
