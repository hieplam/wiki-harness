## Goal

Prove `c3-2` (lifecycle) behaves correctly end-to-end — a fresh `init` lands lint-clean with a
real commit, `upgrade` refuses before writing on drift/downgrade/dirty-tree, promotes atomically,
and the HARNESS finding fires exactly when it should.

## Purpose

Own `tests/test_init.py` (plus the tracked-`CLAUDE.md` and `source_url` assertions),
`tests/test_upgrade.py` (including the fatal-flaw-resolution test and the simplified
try/except-rollback, downgrade-guard, and missing-file drift tests — no marker-file-aware branch
anywhere, per A3), and `tests/test_harness_integrity.py` (the `HARNESS`-finding tests, also with
no marker-aware branch). Non-goal: this component never tests `c3-1`'s check logic directly — it
tests the *decision to run* `lint.py` as a subprocess self-check inside `init`/`upgrade`, not the
check logic itself, which is `c3-410`'s subject.
