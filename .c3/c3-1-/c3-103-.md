## Goal

Validate a proposed commit message's format at commit time and report every violation, so a
malformed commit message never lands.

## Purpose

Own `scripts/check_commit_msg.py`: `validate(message: str) -> list[str]`, the pure function that
returns every format violation found in a commit message text, and the thin `main(msg_file: str)
-> int` edge that reads the message file from disk and prints/returns an exit code. Non-goal:
this component never inspects the git object database or staged diff — it only ever sees the
message text itself.
